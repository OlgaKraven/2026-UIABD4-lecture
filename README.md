# МДК.07.01 — 4-й курс

Адаптивный сайт-презентация по дисциплине «Управление и автоматизация баз данных». Курс охватывает 10 утверждённых лекционных тем (7 и 8 семестр), каждая тема строится генератором `buildDeck(topic, course)` и содержит ровно 85 экранов: 80 базовых и 5 служебных.

## Демонстрационный экзамен 2027

Лекции 4-го курса сверены с КОД `09.02.07-5-2027` для квалификации «Специалист по информационным системам». Утверждённые темы и число экранов сохранены. В каждой лекции экран 02 показывает связь с заданиями ДЭ, экран 08 задаёт тренировку по формату КОД, практические экраны содержат экзаменационные критерии, а экран 83 — чек-лист готовности.

| Тема | Связь с заданиями ДЭ | Проверяемый результат подготовки |
|---|---|---|
| Запросы на серверной базе и рост данных | 1–3, прямая | ER-диаграмма, серверная БД, контрольный SQL |
| Расчётный запрос и проверка правдоподобия | 3, прямая | стоимость заказа с материалами, операциями и нормой расхода |
| Хранимые процедуры и триггеры | 4–6, поддерживающая | прозрачная логика модулей ИС и API, тесты и документация методов |
| Производительность запросов и индексы | 3, 5, поддерживающая | план запроса и сохранение корректности результата |
| Требования к серверу и сети | 2, 4, 5, поддерживающая | готовая СУБД, среда разработки и опубликованный HTTP-сервис |
| Показатели работы сервера | 2, 5, поддерживающая | доказательная карточка технической проблемы |
| Сбор показателей во времени | 5, поддерживающая | проверка доступности, статуса и формата ответа API |
| Панель наблюдения и оповещения | 5, поддерживающая | контроль 200/500 и валидности JSON |
| Разбор инцидента и восстановление | 2, 5, поддерживающая | воспроизведение 500 и подтверждение восстановления |
| Сравнение MySQL и PostgreSQL | 1–5, поддерживающая | обоснованный выбор СУБД и перенос контрольного решения |

Экзаменационная цепочка: 20 минут на ER-диаграмму, 30 минут на БД и импорт JSON, 20 минут на расчётный SQL, по 60 минут на модули ИС и интеграцию API, 20 минут на проектную документацию. Эти интервалы являются ориентирами; итог сдаётся по окончании общего времени ДЭ.

## Возможности

- каталог, поиск и фильтрация по семестру;
- прямые ссылки вида `?topic=[TOPIC_ID]&slide=[1..85]`;
- клавиатурная навигация, полноэкранный режим, светлая и тёмная темы;
- сохранение профиля преподавателя, прогресса и ответов в `localStorage`;
- шесть тематических заданий, отдельное окно результата и ручная самопроверка короткого ответа;
- статический маршрут `/print?topic=[TOPIC_ID]&variant=student|teacher`;
- PDF на 85 страниц для студента и преподавателя;
- явная трассировка каждой темы к КОД `09.02.07-5-2027`, продуктам и типичным ошибкам ДЭ;
- локальный Raleway, фирменный логотип, общий DBA-носорог и проверенный QR-код.

## Команды

```bash

npm run test

npm run build

npm run export:pdf
```
