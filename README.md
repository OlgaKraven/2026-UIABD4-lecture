## Работа с курсом

Лекции используют `public/course.json`; учебные ключи находятся отдельно в `public/assessment.json`. Это автономная самопроверка, а не защищённый экзамен. Старые ссылки `?topic=...&slide=N` открывают соответствующий материал новой версии. Старые оценки не переносятся.

Сценарий создаётся одновременно со слайдами в `private/teacher-pack.json`. У каждой заметки есть стабильный ID, текст объяснения, подготовка, запись, вопросы, разбор и расчёт времени. Производный `private/teacher.md` создаётся из того же источника. Приватные файлы не входят в Git и сборку.

Чтобы пользоваться сценарием на своём устройстве: откройте лекцию → «Начать занятие в двух окнах» → «Загрузить заметки» → выберите переданный `teacher-pack.json` → «Применить заметки». Импорт всего курса выполняется один раз в браузере. При смене браузера или очистке его данных импорт повторяется. Перед повторной генерацией ручные правки защищены сравнением с предыдущим сгенерированным сценарием.

ФИО и подразделение задаются через «Настройка перед занятием». Они не выдуманы и не подставлены из демонстрации. Локальный редактор использует профиль доступа из переданной пользователем инструкции; plaintext-пароль не публикуется. Редактор не является серверной защитой содержимого.

## Команды

Node.js 24, npm. После клонирования:

```sh
npm ci
npm run validate:content
npm run check:teacher
npm run typecheck
npm run lint
npm run test
npm run build
npm run check:privacy
npm run preview
```

После установки отдельно переданного приватного комплекта (включая `private/migrate.mjs`) команда `npm run migrate` воспроизводит курс, банк, сценарий и карты из исходной структуры и `authoring/examples.mjs`. Не запускайте его поверх отредактированного публичного JSON без переноса изменений в авторские исходники. `npm run test` проверяет сохранённую исходную модель; проверка новой модели выполняется `validate:content`. Отчёт о фактических браузерных проверках — `reports/QUALITY.md`.

Ученические PDF создаются из печатного рендера того же курса:

```sh
npm run export:pdf -- --variant student
npm run export:pdf -- --topic s07-01-queries-on-server-database --out outputs/pdf/student
npm run check:pdf
```

Экспорт требует доступного Google Chrome. Один слайд соответствует одной странице 16:9. Вариант PDF со сценариями не публикуется. Заметки передаются отдельно.

## Карты и публикация

- `authoring/questions.json`: 80 вопросов, объясняющие слайды и задания.
- `reports/migration-map.json`: все 850 исходных экранов и цели переноса.
- `reports/registry.json`: количество слайдов, заданий, схем и оценки времени.
- `reports/progress.json`, `reports/QUALITY.md`: статус и границы проверок.
- `src/data/sourceRegistry.ts`: исходный реестр источников; его прежние даты не считаются новой проверкой.

Публикация выполняется существующим GitHub Actions workflow после обновления `main`. Он проверяет данные, код, сборку и отсутствие приватных сценариев. Исходный репозиторий шаблона не изменяется.
