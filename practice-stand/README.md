# Учебный стенд MySQL для УИАБД, 4 курс

Windows x64, PowerShell 5.1 или новее, доступ к официальному архиву MySQL. Docker, установленный клиент и регистрация службы не требуются. Первый запуск скачивает около 270 МБ и сверяет SHA-256; повторный использует подготовленный экземпляр.

Распакуйте весь комплект в одну папку. Откройте в ней PowerShell:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\start.ps1
.\client.ps1
```

Стенд слушает только `127.0.0.1:33064`. Созданы база `uiabd4_training` и пользователь `student` с правами на эту базу. Пароли случайные, создаются на вашем компьютере; клиент использует их без вывода в консоль. Программы, данные и секреты хранятся отдельно от распакованных материалов: `%LOCALAPPDATA%\UIABD4-study`. Не передавайте содержимое этой папки в общий репозиторий.

В открытом клиенте:

```sql
SELECT VERSION(), CURRENT_USER(), DATABASE();
SOURCE sql/01-queries.sql;
```

Ожидаются MySQL 8.4.13 и база `uiabd4_training`. WHERE возвращает 101, 103, 104; последующие запросы файла демонстрируют агрегаты, пары и группы. Временные таблицы существуют в этом сеансе. Для нового прохода файла откройте новый клиент; не запускайте его повторно поверх тех же временных таблиц.

Вместо интерактивного клиента файл можно выполнить целиком:

```powershell
.\client.ps1 -File .\sql\01-queries.sql
```

Для упражнений, создающих отдельные базы, роли и пользователей, откройте административный сеанс **этого учебного экземпляра**:

```powershell
.\client.ps1 -Admin
```

У новых пользователей, созданных упражнением через `RANDOM PASSWORD`, сохраните выданный пароль локально. Вход под такой записью:

```powershell
.\client.ps1 -User uiabd4_readonly
```

Клиент запросит пароль. Базовый `student` не получает глобальные полномочия ради работы с одной базой.

Штатный останов сохраняет данные:

```powershell
.\stop.ps1
```

Повторный `start.ps1` запускает тот же экземпляр. Папка не очищается, чужие каталоги не переинициализируются. Для второго независимого экземпляра укажите новую пустую папку `-Root` и свободный `-Port`; эти же `-Root` используйте в client.ps1 и stop.ps1.

Файлы `sql/` содержат практические наборы MySQL, а `monitoring/` — экспортёр и конфигурации для отдельных тем. PostgreSQL и Prometheus не являются частью этого MySQL-процесса. Их среда и команды явно описаны в соответствующих лекциях; установочные источники: [PostgreSQL для Windows](https://www.postgresql.org/download/windows/), [Prometheus](https://prometheus.io/download/), [Python](https://www.python.org/downloads/windows/). MySQL-стенд не выдаётся за уже установленный PostgreSQL или сборщик метрик.
